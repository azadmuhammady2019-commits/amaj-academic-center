# آموزشگاه علمی آماج

**Amaj Academic Center** — A comprehensive management system for educational academies

## ✨ Features

- 📊 **Dashboard**: Overview of students, teachers, classes, fees, and expenses
- 👥 **Student Management**: Track student information, levels, and assignments
- 👨‍🏫 **Teacher Management**: Manage teacher information and contracts
- 📚 **Class Management**: Organize classes by level and schedule
- 💳 **Fee Tracking**: Record and monitor student fee payments
- ✅ **Attendance**: Track class attendance records
- 📝 **Exam Results**: Store and view exam scores and results
- 📖 **Book Inventory**: Manage textbook inventory and distribution
- 💰 **Expense Tracking**: Record operational expenses
- 💾 **Backup & Restore**: Download and restore data as JSON files
- 🔒 **Local Storage**: All data is stored locally in browser

## 🛠 Tech Stack

- **Vue 3**: Progressive JavaScript framework
- **Vite**: Next generation build tool
- **Local Storage**: Browser-based data persistence

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The application will open at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 📖 Usage

1. Navigate through the different sections using the navigation bar
2. View and manage all academy data in the dashboard
3. Use the backup feature to download/restore data as JSON
4. All changes are automatically saved to browser local storage

## 📊 Data Structure

The application uses the following main data categories:

- **Students**: Full student information including contact details
- **Teachers**: Teacher profiles and contract information
- **Classes**: Class schedules and assignments
- **Fee Payments**: Student fee records and receipts
- **Attendance**: Class attendance tracking
- **Exams**: Student exam results and scores
- **Books**: Textbook inventory management
- **Expenses**: Academy operational expenses

## 💾 Features

### Local Storage
All data is persisted in browser's localStorage, ensuring data survives page refreshes and browser restarts.

### Backup System
- Download all data as a JSON file
- Restore from previously downloaded JSON files
- Easy data migration between devices

### Responsive Design
The application is fully responsive and works on desktop, tablet, and mobile devices.

### Search Functionality
Quick search through student records by name, ID, or level.

## 📱 Responsive Layout

- Desktop: Full layout with multiple columns
- Tablet: Optimized grid layout
- Mobile: Single column, touch-friendly interface

## 🌐 Language

- Primary Language: Farsi (Persian)
- Interface Direction: RTL (Right-to-Left)
- Supports all Farsi text and numbers
